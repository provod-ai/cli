# provod

Short npm alias for the Provod CLI.

```bash
npx provod setup
npx provod setup --token '<provider-token>'
```

This package delegates to the published [`@provod-ai/cli`](https://www.npmjs.com/package/@provod-ai/cli) package and forwards command-line arguments, standard input/output, exit codes, and termination signals.

Requires Node.js 18.18 or newer. Supported platforms are macOS and Linux on arm64 or x64.
